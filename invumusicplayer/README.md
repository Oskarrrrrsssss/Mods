# invumusicplayer — Minecraft Java 26.3 / Fabric / Windows

**Русский** · [English](README.en.md)

Клиентский плеер: Яндекс Музыка, «Моя волна», локальная музыка и звук YouTube.
Окно во время игры можно перемещать, масштабировать, менять его цвета и прозрачность.
Интерфейс использует язык Minecraft: русский или английский.

Крупная обложка расположена по центру правой части главного плеера; название и исполнитель — под ней, громкость — отдельной строкой под управляющими кнопками. На маленьком экране карточка подстраивается под свободное место. Плеер, библиотека и их кнопки используют цвета текущей обложки; настройки сохраняют постоянную палитру.

В **Настройки → Вид** есть такой же переключатель и отдельная **Анимация обложки**: мягкое движение цветного свечения за картинкой в полном и мини-плеере. На паузе движение замирает; при отключённом фоне по обложке свечение скрывается.

- На «+» в библиотеке появляется подсказка **Добавить в очередь**, на «×» очереди — **Удалить из очереди**.
- Пауза возвращена в главное окно плеера между предыдущим и следующим треком. Стоп и кнопки ±10 секунд по-прежнему убраны; перемотка доступна ползунком.
- Перемешивание мини-плеера действует и на продолжение после «Предыдущего». Один клик меняет порядок предстоящих разных треков без перезапуска текущего; повторный клик выключает режим и восстанавливает порядок. Значок показывает выбранное состояние, подсказка — включён ли режим.
- Кнопка **часов** в мини-плеере скрывает/возвращает время во всех плеерах. Ползунок перемотки остаётся доступен; числовое время и его подсказка скрыты. Изменение сохраняется.
- **Настройки → Мини-плеер** (бывшая «Видимость»): время, показ при F1, отдельная видимость плееров и ползунки ширины эквалайзера **25–100%**, высоты **50–200%**. Размер относится к графике, не к громкости; на маленьком экране полный плеер ограничивает высоту свободным местом.
- Из общих настроек убраны кнопки «Положение в меню» и «Переместить панель». Редакторы остаются доступны через значки перемещения в самих плеерах.
- Исправлен показ при F1: музыкальный слой подключён к слою интерфейса, который вызывается при скрытом HUD. «Скрыть все» и индивидуальное отключение остаются приоритетными.


## Изменения 0.2.8

Очередь находится на главной странице плеера. Поиск перенесён в **Библиотека → Поиск**; кнопка **Локальные** переключает поиск по файлам папки `music`. Колёсико листает страницы очереди или библиотеки. Нажатие на трек очереди запускает его; «×» убирает его из очереди.

Ползунок позиции показывает прошедшее и полное время. Перетаскивание предварительно выбирает позицию; отпускание мыши перематывает один раз. Если во время перетаскивания сменился трек, перемотка отменяется. Пауза сохраняется при перемотке. Кнопки Стоп и ±10 секунд убраны. Пауза доступна в главном и мини-плеере и по горячей клавише. Время и включённый эквалайзер видны одновременно в HUD, меню и полном плеере.

Перемешивание меняет предстоящие треки, включая вручную добавленные, и не перезапускает текущий. При нескольких разных треках порядок обязательно меняется. Вручную добавленные треки сохраняют приоритет перед основным списком. Выключение восстанавливает порядок оставшихся треков; история «Назад» сохраняется.

Локальные обложки: сначала `Название.png/.jpg/.jpeg/.webp`, затем `cover.png/.jpg/.jpeg/.webp` или `folder.jpg` в той же папке, затем встроенная ID3 APIC/PIC-обложка MP3 либо METADATA_BLOCK_PICTURE/COVERART в Ogg/Vorbis. Обложки читаются вместе с треком и видны в библиотеке и плеере; отключение обложек оставляет текст. Повреждённые теги не блокируют музыку.

## Spotify: звук внутри мода (экспериментально)

**Настройки → Управление → Музыкальный сервис** или **Аккаунт**: выбери Spotify / Яндекс Музыку. Spotify использует встроенный нативный декодер librespot и передаёт звук в системное аудиоустройство через JavaSound; приложение Spotify не требуется. Это неофициальная интеграция: воспроизведение с настоящим аккаунтом Premium пока не подтверждено. Автоматические проверки покрывают авторизацию с тестовыми ответами, каталог и нативный аудиоканал с синтетическим сигналом.

Нужен **Spotify Premium**, доступ к Spotify и свой Client ID из [Developer Dashboard](https://developer.spotify.com/dashboard). Client Secret, пароль и токены в чат вводить не нужно.

1. Создай Web API приложение; добавь точный Redirect URI `http://127.0.0.1:43827/callback`. В Development Mode добавь свой аккаунт в список разрешённых пользователей. Доступность создания приложений и квоты задаёт Spotify.
2. В моде выбери Spotify, вставь **Client ID** и нажми **Вход в каталог**. В браузере разреши доступ к каталогу/библиотеке.
3. Нажми **Включить встроенный звук** и пройди отдельный вход в тот же Premium-аккаунт. Для декодера используется собственная идентичность librespot, а не Client ID твоего Web API приложения. Второй callback — `http://127.0.0.1:8898/login`; этот адрес не нужно добавлять в своё приложение. Вход отменяется через пять минут; если порт занят, мод покажет ошибку.
4. В **Библиотека → Поиск** найди трек и нажми на название. Доступны понравившиеся, плейлисты, очередь, пауза, перемотка и громкость. Можно импортировать HTTPS-ссылки `open.spotify.com/track/...` и `/playlist/...`.

В режиме разработки Spotify поиск ограничен десятью результатами на запрос; содержимое плейлистов может быть доступно только владельцу/соавтору. Повторный лайк убирает лайк. Удаление Spotify-плейлиста в моде убирает его из твоей библиотеки, не удаляя сам плейлист у автора. «Моя волна» и дизлайк относятся к Яндекс Музыке и отключены для Spotify. Смена сервиса сохраняет очередь, останавливая текущее аудио до выбора/возобновления трека.

На Windows данные двух входов сохраняются раздельно, зашифрованные DPAPI: `config/invumusicplayer-spotify-auth.dat` и `config/invumusicplayer-spotify-playback.dat`. Client ID сохраняется в настройках; секреты туда не пишутся. **Отключить** убирает оба входа. Звук Spotify не экспортируется в файлы и не кэшируется на диске. Проверенный по SHA-256 движок извлекается из JAR в `tools/invumusicplayer/spotify`; Rust для установки готового мода не нужен. Spotify-интеграция рассчитана на Windows x64; Linux x64 используется для проверки движка и интерфейса в CI.

Для сборки из исходников нужны **JDK 25, Rust/Cargo и Python 3**. Gradle автоматически собирает и упаковывает нативный движок; версии зависимостей зафиксированы в `native-spotify/Cargo.lock`. Первичная сборка требует скачивания Rust-зависимостей. Источники и ограничения: [librespot](https://github.com/librespot-org/librespot), [Spotify PKCE](https://developer.spotify.com/documentation/web-api/tutorials/code-pkce-flow), [Development Mode](https://developer.spotify.com/documentation/web-api/concepts/quota-modes).


## Исправление предыдущего трека (0.2.7)

Одно нажатие «Предыдущий» возвращает на один шаг по истории переключений: ручная очередь, перемешивание, выбор из списка и переходы между партиями Моей волны. Быстрые переключения сохраняются и во время загрузки. У начала списка первый трек перезапускается вместо перехода к последнему.

«Следующий» возвращает вперёд по этой истории, затем продолжает плейлист/волну. Продолжение отображается в очереди и сохраняется при перезапуске. Кнопки полного плеера/Escape и горячая клавиша используют одну навигацию.

## Видимость плееров и колёсико (0.2.6)

**Настройки плеера → Мини-плеер**: отдельные кнопки для плеера в игре, мини-плеера главного меню и мини-плеера Escape. **Скрыть все** временно скрывает все три плеера вместе с их кнопками, не останавливая музыку и не меняя отдельные переключатели. В главном меню остаётся только мини-плеер; отдельной кнопки invumusic нет.

Чтобы вернуть скрытые плееры, открой **Настройки Minecraft → Настройки плеера → Мини-плеер**. Этот путь работает до входа в мир. В игре полный плеер также доступен по назначенной горячей клавише.

Колёсико над списком треков полного плеера перелистывает страницы. Прокрутка вне списка не меняет страницу и не переключает музыку.

## Эквалайзер и навигация (0.2.6)

FFT измеряет декодированный звук **до применения громкости**. Уменьшение громкости, включая 0% на ползунке, не уменьшает полосы эквалайзера. Пауза и тишина в самой записи по-прежнему останавливают или гасят полосы. Ползунок продолжает менять настоящий звук.

В общих настройках доступны **Управление**, **Вид** и **Мини-плеер**. Настройки Моей волны открываются отдельной кнопкой из главного меню и полного плеера. Дублирующая вкладка волны и громкость из общих настроек убраны.

В полном плеере также подсвечивается текущий трек; недоступные стрелки страниц отключаются. Сохранённая волна восстанавливает правильный раздел и список текущей/следующих песен. В редакторе меню доступны все четыре угла и свободное перетаскивание; значок библиотеки изображает открытую книгу. Открытие аккаунта из плеера в меню Escape сохраняет паузу одиночного мира.

## Компактный плеер в меню (0.2.6)

В главном меню и Escape отображается компактная карточка альбома. Стандартный масштаб — 50%; большая кнопка сверху убрана. Значок ноты под карточкой открывает полный плеер. Остальные значки открывают настройки, Мою волну, библиотеку и редактор положения в меню. При выходе из мира музыка продолжает играть.

Ползунок громкости в меню находится на отдельной строке с пустым отступом сверху. В полном плеере громкость тоже отделена от переключения треков. Из настроек громкость убрана. Изменения применяются сразу и сохраняются.

**Положение в меню** открывает отдельный редактор: перетащи карточку, измени масштаб, выбери угол или сбрось положение. Размер и позиция применяются к главному меню и Escape и сохраняются между запусками. Для игрового HUD остаётся независимый редактор. **Цвета обложки** окрашивают и плеер в меню, и игровой HUD; отключи настройку, чтобы использовать свои цвета.

Текущие вкладки настроек и библиотеки, а также выбранный трек подсвечены. В библиотеке есть обложки, номер страницы и активные стрелки назад/вперёд. Колесо мыши над списком тоже листает страницы. **Понравившиеся → Играть понравившиеся** запускает весь список, включая песни с других страниц. Удаление локального или своего Яндекс-плейлиста по-прежнему требует подтверждения.

Ручные метки и фильтр настроения в понравившихся убраны: доступные метаданные треков Яндекса не содержат надёжного настроения для такой фильтрации. Настроение остаётся в **настройках Моей волны**, доступных из главного меню. После каждой смены песни список волны сдвигается: показывает текущую и следующие песни, сохраняя отдельно открытые результаты поиска или библиотеку. Новые партии рекомендаций загружаются автоматически.

Перемешивание, повтор, переключаемые лайк/дизлайк и настраиваемые горячие клавиши сохранены. Повторный лайк только снимает лайк. Токен, очередь, плейлисты и настройки сохраняются локально.

## Предыдущие исправления


- Обложки запрашиваются в стандартном размере Яндекса `200x200`; старые адреса `256x256` исправляются автоматически. При устаревшем адресе запрашиваются полные данные трека. Обложка загружается сразу, параллельно звуку. Ошибки больше не скрываются и не оставляют пустую иконку навсегда. JPEG, PNG и WebP поддерживаются.
- Щелчок в очереди запускает выбранный трек без копирования и повторов оставшихся треков. Сохраняются текущий трек, порядок следующих треков и продолжение «Моей волны». Введённые ссылки и названия плейлистов сохраняются при обновлении списка.
- Плавный эквалайзер включён по умолчанию в игровом окне и плеере. 24 частотные полосы рассчитываются по настоящему звуку через FFT. Он не зависит от ползунка громкости и затухает при паузе и не создаёт движение в тишине. В настройках можно вернуть время и полосу прогресса.
- На Windows x64 инструменты YouTube — yt-dlp, Deno, FFmpeg и ffprobe — подготавливаются автоматически при первом импорте ссылки. Их загрузки проверяются SHA-256. Звук преобразуется в MP3 вместо большого WAV. Отображаются подготовка и понятные ошибки доступа.
- **3D-субтитры полностью удалены**: нет вкладки, горячей клавиши, рендера и запросов текста из Яндекса. Надёжная работа синхронного текста с настоящим аккаунтом не подтверждена.

## Установка

1. Скачай Windows-артефакт из успешного запуска [GitHub Actions](https://github.com/Oskarrrrrsssss/Mods/actions/workflows/invumusicplayer.yml). Для приватного репозитория нужно войти в GitHub.
2. Извлеки ZIP. Помести **invumusicplayer-0.2.9-alpha.jar** в `mods` нужного экземпляра Minecraft.
3. Установи Fabric Loader и Fabric API для **26.3**, используй Java 25.
4. Удали предыдущий JAR Musicraft/invumusicplayer из `mods`, чтобы не было двух копий мода. Настройки, очередь и авторизация сохраняются.
5. Нажми значок ноты в мини-плеере главного меню или **M** в мире.

Для стандартного лаунчера папка игры — `%APPDATA%\.minecraft\`. Другие лаунчеры могут использовать отдельные папки экземпляров.
Не устанавливай `-sources.jar` или `-gametest.jar`.

## Управление

| Клавиша | Действие |
|---|---|
| M | Открыть плеер |
| F7 | Предыдущий трек |
| F8 | Воспроизведение / пауза |
| F9 | Следующий трек |

Лайк и дизлайк доступны кнопками, их горячие клавиши изначально не назначены.
Настроить все клавиши можно через **Настройки плеера → Горячие клавиши** или управление Minecraft.

**Настройки → Вид**: обложки, эквалайзер, прозрачность и RGB-цвета фона, текста и акцента.
**Положение HUD**: перетаскивание, четыре угла и масштаб. Громкость изменяется ползунком.
**Настройки → Управление → Обновить обложку**: повторить загрузку обложки текущего трека.
Полная ошибка и состояние обложки видны при наведении на статус плеера. Ошибка импорта видна и в библиотеке.

## Яндекс Музыка и очередь

Открой **Аккаунт**, вставь свой OAuth-токен Яндекс Музыки или официальный URL с `access_token` и нажми **Подключить**.
Пароль не нужен. Получение токена описано в [инструкциях неофициальной библиотеки](https://yandex-music.readthedocs.io/en/main/token.html).
Вводи токен только локально в моде.

Поиск, «Моя волна», лайки и дизлайки используют неофициальный API. Нужны действующий токен, доступ к сервису и соответствующая подписка. Ограничения региона и доступность треков определяет Яндекс.
Пользователь подтвердил воспроизведение и волну в предыдущей сборке; изменения сетевых функций требуют проверки с настоящим аккаунтом.

**Настройки Моей волны**: весёлое, грустное, спокойное, энергичное или любое настроение; избранное, популярное, открытие или сбалансированный режим; язык. Нажми **Применить**, чтобы начать новую волну.
По окончании порции рекомендаций запрашивается следующая. Недавно выданные треки фильтруются и после восстановления сессии.

**+** добавляет трек в ближайшую очередь. **Главный плеер → Очередь** показывает следующие треки без текущего: нажми на название для воспроизведения или **×** для удаления. Добавленные вручную треки играют перед продолжением плейлиста/волны.
**Очистить** оставляет текущую музыку и отменяет дальнейшую очередь, включая автопополнение волны.
**Понравившиеся** загружаются из аккаунта. **Плейлисты** показывает плейлисты аккаунта и сохранённые локально.
Вставь ссылку Яндекса вида `/users/имя/playlists/номер` или `/playlists/uuid` для импорта.
Введи название и нажми **Сохранить очередь**, чтобы создать локальный плейлист; он не публикуется в Яндекс.

## YouTube — только звук

В **Библиотеке** вставь HTTPS-ссылку на обычное публичное видео, Shorts или `youtu.be`, нажми **Импорт**.
Трек появится во вкладке **Треки** и очереди. Нажми его название, чтобы слушать.
Обложка скрывается, длинное название сокращается; видеоряд не загружается в плеер.

При первом использовании на **Windows x64** мод загружает около 240 МБ инструментов в `tools/invumusicplayer` внутри папки этого экземпляра игры. Нужен доступ к GitHub. Установка идёт в фоне, её состояние видно в библиотеке; повторный импорт использует сохранённые инструменты.
yt-dlp и Deno имеют закреплённые версии; для сборки FFmpeg LGPL используется проверяемый SHA-256 из официального релиза BtbN.
Инструменты не получают токен Яндекса или cookies браузера.

Можно положить собственные `yt-dlp.exe`, `deno.exe`, `ffmpeg.exe` и `ffprobe.exe` прямо в `tools`: полный набор используется вместо автоматической установки. На Linux/macOS установи yt-dlp, Deno и FFmpeg в PATH либо `tools`; автоустановка рассчитана на Windows x64.
Источники: [yt-dlp](https://github.com/yt-dlp/yt-dlp), [Deno](https://github.com/denoland/deno), [FFmpeg](https://github.com/BtbN/FFmpeg-Builds).

Закрытые видео, требование входа/проверки бота, трансляции и ограничения региона не обходятся. Если YouTube запрещает запрос, показывается причина. Работа с конкретным видео зависит от YouTube и сети.
Звук полностью загружается перед воспроизведением: до **128 МиБ** на YouTube-трек, до **64 МиБ** на трек Яндекса. Временные файлы YouTube удаляются после загрузки или отмены.

## Локальная музыка и сохранение

Помести MP3, WAV или OGG/Vorbis в `music` внутри папки игры, затем нажми **Локально**, чтобы обновить список. Для обложки используй соседний PNG/JPG с тем же именем. Для названия и исполнителя — необязательный UTF-8 JSON:

```text
music/
  Artist - Title.mp3
  Artist - Title.png
  Artist - Title.json
```

```json
{"title":"Название", "artist":"Исполнитель"}
```

Без JSON используется имя файла; при отсутствии соседней картинки читается встроенная MP3 ID3-обложка или Ogg picture-comment. Старые `.lrc` не используются.
Настройки доступны до входа в мир. При выходе из мира звук продолжает играть, текущий трек и очередь сохраняются. В главном меню можно управлять продолжающейся музыкой.
Токен хранится в `config/invumusicplayer-auth.dat`, зашифрованный Windows DPAPI для текущего пользователя; **Отключить** удаляет его. Настройки — `config/invumusicplayer.json`, очередь и локальные плейлисты — `config/invumusicplayer-session.json`.

## Сборка и проверка

Нужны JDK 25, Rust/Cargo, Python 3 и интернет. В папке `invumusicplayer`:

```bat
build-windows.cmd
```

Либо `gradlew.bat build`; на Linux — `bash ./gradlew build`. Результат — `build/libs/invumusicplayer-0.2.9-alpha.jar`.
Gradle Wrapper 9.7.1, Loom 1.18.4, Fabric Loader 0.19.5, Fabric API 0.162.0+26.3. Minecraft 26.3 использует необфусцированные имена, Yarn не нужен.
Тесты: `gradlew.bat test`. Проверка настоящего клиента: `gradlew.bat runProductionClientGameTest`; тестовый мод не входит в установочный JAR.
Проверка Windows-инструментов без скачивания видео: `gradlew.bat verifyYouTubeTools`.
Результаты и границы проверки — [VALIDATION.md](VALIDATION.md), зависимости — [THIRD_PARTY.md](THIRD_PARTY.md).
Если проблема остаётся, пришли версию и текст ошибки из статуса; не отправляй токен. Лог игры — `logs/latest.log`.
