# InvuMusicPlayer — Minecraft Java 26.3 / Fabric / Windows

**Русский** · [English](README.en.md)

Клиентский музыкальный мод: свои треки, поиск Яндекс Музыки, «Моя волна»,
обложки и синхронные 3D-субтитры перед игроком. Панель плеера можно перемещать и масштабировать.
**Интерфейс следует языку Minecraft:** русский для русского языка, английский для остальных.
Названия песен, исполнители и текст песни остаются на языке источника.

Предыдущая версия прошла **62 теста на Windows**, включая DPAPI. Для этого обновления смотри CI и отчёт проверки в ZIP.
Интерфейс и рендер проверены в настоящем Minecraft 26.3 на Linux.
**Воспроизведение Яндекс Музыки с настоящим аккаунтом ещё не проверено.**
Подробности: [результаты проверки](VALIDATION.md).

## Изменения в 0.2.0

- Плоские кнопки заменили стиль Minecraft. Плеер открывается из главного меню до входа в мир.
- Ползунок громкости сразу меняет звук. Для HUD доступны прозрачность, RGB-цвета акцента, фона и текста, а также масштаб.
- Спектр настоящего PCM-звука можно включить вместо времени и полосы прогресса. Для YouTube обложка скрыта: остаётся сокращённое название видео, играет только звук.
- 3D-текст показывает только текущую синхронную строку, без тени и подложки. Ограничение «только при беге» отключаемое; плеер показывает наличие текста или ошибку загрузки.
- Выбор трека Моей волны сохраняет режим радио. В конце партии запрашиваются новые рекомендации вместо повтора тех же пяти треков.
- Обложки берутся также из метаданных альбома; поддерживаются JPEG, PNG и WebP. Текст и картинки загружаются независимо.
- Лайк и дизлайк текущего трека Яндекса, раздел «Понравившиеся», плейлисты аккаунта и импорт ссылки на плейлист. Кнопка + добавляет трек в очередь; в библиотеке её можно очистить или сохранить как именованный **локальный плейлист**. Локальные плейлисты не публикуются в Яндекс.
- Настройки волны: весёлая, грустная, спокойная, бодрая или любое настроение; баланс, любимые, популярные или открытия. Применение запускает новую волну с выбранными предпочтениями.
- F10 включает Мою волну. Все горячие клавиши, включая изначально неназначенные лайк и дизлайк, меняются кнопкой «Горячие клавиши» или в управлении Minecraft.
- При выходе из мира звук останавливается, очередь и плейлисты сохраняются. Зашифрованный Windows-токен восстанавливается при запуске. Настройки и токен Musicraft переносятся автоматически; перед установкой удали старый JAR мода.

### Необязательный звук YouTube

Для публичного HTTPS-видео положи **yt-dlp.exe** и **ffmpeg.exe** в папку `tools` текущей игры либо установи yt-dlp и ffmpeg в PATH. Официальные источники: https://github.com/yt-dlp/yt-dlp и https://ffmpeg.org/download.html. Эти инструменты необязательные: в мод не включены и автоматически не устанавливаются.
Вставь URL в **Библиотека → поле ссылки → Вставить**, затем выбери видео в плеере или запусти очередь. Мод загружает звук, преобразует его в WAV и удаляет временные файлы после чтения. Видео и превью не отображаются. Плейлисты, прямые трансляции, вход с cookies и ограниченные видео не поддерживаются. Звук ограничен 128 МиБ, извлечение — 3 минутами; ошибка инструмента или сервиса показывается в плеере.

## Установка

Нужны **Minecraft Java 26.3**, **Java 25**, **Fabric Loader 0.19.5+** и
**Fabric API 0.162.0+26.3**. Мод устанавливается только на клиент.

1. Открой [GitHub Actions](https://github.com/Oskarrrrrsssss/Mods/actions/workflows/invumusicplayer.yml)
   и выбери успешный запуск. Для закрытого репозитория нужен доступ к нему и вход в GitHub.
2. Скачай артефакт `invumusicplayer-fabric-26.3-windows-latest` и распакуй ZIP.
3. Положи `invumusicplayer-0.2.0-alpha.jar` в папку `mods` выбранной сборки Minecraft.
   Fabric API также должен быть установлен в `mods`.
4. Запусти игру и нажми **M**. Добавь локальные файлы или подключи аккаунт Яндекс Музыки.

В архиве рядом с JAR находятся русские и английские инструкции `README`, результаты проверки `VALIDATION` и сведения о зависимостях `THIRD_PARTY`.

Для обычного лаунчера папка игры — `%APPDATA%\.minecraft\`.
У отдельной сборки лаунчера используется её собственная папка.
`-sources.jar` и `-gametest.jar` устанавливать не нужно.

## Управление и внешний вид

| Клавиша | Действие |
|---|---|
| M | Открыть плеер |
| F7 | Предыдущий трек |
| F8 | Играть / пауза |
| F9 | Следующий трек |
| K | Включить / выключить 3D-субтитры |

Переназначение: **Настройки Minecraft → Управление → Назначение клавиш → InvuMusicPlayer**.
Клавиши работают без открытия плеера. Окна InvuMusicPlayer не останавливают игру.

- По умолчанию панель находится слева сверху и показывает обложку, название, исполнителя и прогресс.
- **Плеер → Настройки → Переместить панель:** перетащи панель мышью в любое место,
  выбери один из четырёх углов, измени масштаб или прозрачность, затем нажми «Готово».
- В настройках можно скрыть панель, отключить обложки для режима с текстом,
  изменить громкость и цвет акцента.
- Там же включаются 3D-субтитры, показ только при беге, расстояние, высота, размер
  и сдвиг синхронизации в миллисекундах. Клавиша **K** быстро переключает субтитры.
  Их отключение не останавливает музыку. Отрисовка локальная, без сущностей и передачи данных на сервер.
- Язык меняется в **Настройках Minecraft → Язык**. Выбери русский или английский;
  отдельного переключателя языка InvuMusicPlayer не требуется.

## Локальные треки

Положи **MP3, WAV или OGG/Vorbis** в `music` внутри папки текущей игры.
В обычном лаунчере это `%APPDATA%\.minecraft\music\`.
Сканирование включает файлы до глубины четырёх уровней от `music`.
После добавления файлов нажми **«Локальные»** в плеере, чтобы обновить список, затем выбери трек.
Аккаунт и интернет для локального воспроизведения не нужны.

Необязательные файлы обложки, метаданных и текста должны иметь то же имя без расширения:

```text
music/
  Исполнитель - Название.mp3
  Исполнитель - Название.lrc
  Исполнитель - Название.png
  Исполнитель - Название.json
```

JSON, сохранённый в UTF-8:

```json
{"title":"Название", "artist":"Исполнитель"}
```

Без JSON название и исполнитель берутся из имени `Исполнитель - Название`.
Без разделителя имя файла используется как название. Обложка — соседний PNG или JPG;
встроенные ID3-обложки не извлекаются. Без обложки и без текста музыка тоже работает.
OGG должен содержать **Vorbis**, а WAV должен поддерживаться JavaSound.

Синхронный текст — соседний `.lrc` в UTF-8. Пример собственного демонстрационного текста:

```lrc
[offset:0]
[00:02.00]Первая строка
[00:05.50]Следующая строка
[00:09.00]
```

Пустая строка с меткой времени скрывает субтитры на инструментальном участке.

## Яндекс Музыка и «Моя волна»

1. Открой **Плеер → Аккаунт**.
2. Вставь OAuth-токен своего аккаунта Яндекс Музыки или официальный адрес страницы
   с параметром `access_token`, затем нажми **«Подключить»**.
3. Вернись в плеер. Используй поиск и выбери найденный трек либо нажми **«Моя волна»**.
   **F9** переключает на следующий трек волны, **F8** ставит паузу.

Пароль мод не запрашивает. Кнопка помощи открывает инструкцию InvuMusicPlayer на русском
и английском. В ней есть ссылка на
[инструкцию библиотеки yandex-music](https://yandex-music.readthedocs.io/en/main/token.html);
эта внешняя инструкция не входит в InvuMusicPlayer и может иметь собственный язык.
Автоматический вход через браузер с собственным зарегистрированным OAuth-приложением
не реализован. Ввод токена происходит локально внутри мода; отправлять его в чат или автору не нужно.

Это **неофициальный API**. Нужны действительный токен Music, доступ к сервису и необходимые
права подписки; регион и доступность треков определяются Яндексом.
Ответы с шифрованием или только превью не выдаются за полный трек.
При отсутствии синхронного текста музыка продолжает играть без субтитров.

Аудио загружается в память до начала воспроизведения, максимум **64 МиБ на трек**,
и не сохраняется в локальную библиотеку. Переключение отменяет предыдущую загрузку.
«Моя волна» использует сессию рекомендаций и отправляет события начала, окончания и пропуска,
учитывая прослушанное время и паузы; перемотка не считается прослушиванием.

Токен маскируется и хранится в `config/invumusicplayer-auth.dat`, зашифрованном Windows DPAPI
для текущего пользователя. В `config/invumusicplayer.json` находятся обычные настройки.
Токен не отправляется на CDN. Для удаления сохранённого входа нажми **«Отключить»**
на экране аккаунта. Перенос файла авторизации на другой ПК или к другому пользователю
не заменяет повторный вход. Сохранение аккаунта рассчитано на Windows.

## Если что-то не работает

| Ситуация | Что проверить |
|---|---|
| Мод не загружается | Версии Minecraft, Java, Fabric Loader и Fabric API; установлен ли обычный JAR. |
| Клавиша не срабатывает | Конфликт назначения в настройках управления; при необходимости переназначь клавишу. |
| Локальных треков нет | Папку именно текущей сборки, расширение MP3/WAV/OGG; нажми «Локальные». |
| Обложки нет | Настройку «Обложки» и соседний PNG/JPG с тем же именем; встроенная ID3-картинка не используется. |
| Субтитров нет | Настройку 3D-субтитров, клавишу K, условие «Только при беге», наличие `.lrc` или текста у Яндекса. |
| Нет звука | Громкость InvuMusicPlayer, микшер и устройство вывода Windows; совместимость формата файла. |
| Вход или «Моя волна» не работают | Сообщение ошибки в плеере, действительность токена, подписку, доступность сервиса и интернет. |
| Не читается сохранённый вход | Подключи аккаунт заново под текущим пользователем Windows. |

Полное сообщение об ошибке можно увидеть в подсказке статуса плеера.
Журнал игры находится в `logs/latest.log` папки текущей сборки.
При обращении за помощью укажи версии и текст ошибки; токен и адрес с `access_token` не прикладывай.

## Сборка из исходников

Перейди в папку `invumusicplayer`. Нужен **JDK 25** через `JAVA_HOME` или `PATH`,
а также интернет для загрузки зависимостей.
Gradle Wrapper 9.7.1 использует Loom 1.18.4; отдельная установка Gradle не требуется.
Игра 26.3 необфусцированная, Yarn/mappings не используются.

Windows:

```bat
build-windows.cmd
```

Или:

```bat
gradlew.bat build
```

Linux:

```sh
bash ./gradlew build
```

Результат: `build/libs/invumusicplayer-0.2.0-alpha.jar`.

## Проверка

Тесты ядра и протокола:

```bat
gradlew.bat test
```

На Linux: `bash ./gradlew test`.
Альтернативная проверка без Loom загружает зависимости с зафиксированными SHA-256:

```powershell
./scripts/verify-core.ps1 -JdkHome 'C:\Path\To\jdk-25'
```

Настоящий клиент с отдельным тестовым модом на Windows:

```bat
gradlew.bat runProductionClientGameTest
```

Для запуска на Linux нужен графический дисплей или Xvfb/Mesa, как в
[CI](https://github.com/Oskarrrrrsssss/Mods/blob/codex/musicraft-playback/.github/workflows/invumusicplayer.yml). Используются синтетические локальные файлы,
без настоящего аккаунта и музыки. [Результаты и ограничения](VALIDATION.md).
[Скриншоты проверенного клиента](https://github.com/Oskarrrrrsssss/Mods/actions/runs/38181353522/artifacts/11717612730).
