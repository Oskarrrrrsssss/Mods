# Результаты проверки

**Русский** · [English](VALIDATION.en.md)

Порт invumusicplayer 0.3.0 для Minecraft 1.20.4 / Fabric / Java 17.

Установочный архив содержит результаты своего CI: ОС, число тестов, ссылку на запуск и SHA-256 JAR. Статистика старой 26.3-сборки к этому порту не относится.

- На Windows/Linux собирается Java 17 JAR, адаптированный к API 1.20.4. Вложенные декодеры MP3/Vorbis/WebP и движок Spotify сохраняются; проверочный мод не упаковывается в JAR.
- Тесты музыкального ядра проверяют очередь, предыдущий трек, перемешивание, Моё волну, локальные обложки, авторизацию и ошибки API на фикстурах.
- Нативный Spotify-процесс передаёт синтетический PCM через рабочий IPC/JavaSound-канал. Проверяются позиция, громкость и независимость FFT от громкости; настоящий Premium-аккаунт в проверке не используется.
- Настоящий клиент 1.20.4 запускается в Linux/Xvfb: проверяются RU/EN, обложки и декодеры, мини-плеер, управление воспроизведением, очередь, библиотека и настройки. Скриншоты и файл результата сохраняются отдельным артефактом CI.
- Windows DPAPI проверяется на Windows. Изменённые операции настоящего аккаунта Яндекса/Spotify, физическое звучание на компьютере пользователя и конкретное YouTube-видео требуют проверки с этим аккаунтом/устройством; автоматические тесты не подтверждают их.

Сервисы и подписки имеют те же требования, что описаны в README. Надёжные синхронные 3D-тексты ранее удалены по запросу пользователя и в порт не возвращены.
