# Результаты проверки

**Русский** · [English](VALIDATION.en.md)

Сборка 0.2.3 проверяет исправления очереди, обложек и спектрального анализатора.
Установочный ZIP содержит в начале этого отчёта результаты конкретного запуска CI, число тестов и SHA-256 JAR.

- Проверены перемешивание без перезапуска текущей песни, обход без повторов, приоритет ручной очереди и восстановление порядка после перезапуска. Повторный лайк только снимает лайк; личные настроения сохраняются и фильтруют песни; удаление плейлиста сохраняет текущий звук.
- Клиент также открывает настройки волны из главного меню, переключает лайк/дизлайк/перемешивание, назначает настроение в понравившихся, фильтрует песни, проверяет обложки библиотеки, отменяет и подтверждает удаление локального плейлиста и продолжает воспроизведение при выходе из мира.
- Тесты очереди проверяют запуск выбранного добавленного трека без повторов, сохранение текущего трека при перезапуске, естественное продвижение, продолжение радио и защиту от устаревших запросов.
- HTTP-тесты используют подставленные ответы: стандартный размер обложки, обновление метаданных после 404, `error: null`, подпись аудио, рекомендации и отсутствие токена на CDN.
- FFT проверяется синтетическими низкими и высокими тонами, стереозвуком, уменьшением громкости и затуханием в тишине.
- Клиентская проверка дополнительно нажимает настоящие Escape/F1, проверяет кнопки управления в меню паузы, возврат из плеера и настроек, сохранение паузы в одиночном мире и оба режима видимости при F1. Скриншоты фиксируют отрисовку; проверяется отсутствие пересечения со стандартными кнопками меню.
- Настоящий Minecraft-клиент на Linux проверяет русские и английские окна, текстуры JPEG/PNG/WebP, готовность двух иконок треков, настройки, HUD и выход из мира. Устройство звука заменено тестовым, поэтому это не проверка слышимого звука на Windows.
- CI пробует скачать общедоступную обложку CDN Яндекса без токена. Если она доступна, клиентский тест использует её; результат отдельно указывается в установочном отчёте. Недоступность внешнего CDN не выдаётся за успешную сетевую проверку.
- Windows CI подготавливает настоящие yt-dlp, Deno, FFmpeg/ffprobe, проверяет их загрузки, запуск и преобразование синтетического тона в MP3 с последующим декодированием JavaSound. Это не проверка воспроизведения конкретного видео YouTube.
- Проверка сохранения токена через Windows DPAPI выполняется на Windows; на Linux пропускается.

Настоящий OAuth-токен не используется в автоматических тестах. Работу изменённой интеграции с аккаунтом Яндекса и воспроизведение конкретных видео YouTube нельзя считать подтверждёнными этими тестами.
3D-субтитры удалены: UI, горячая клавиша, рендер и сетевые запросы текста отсутствуют.
