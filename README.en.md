# InvuMusicPlayer

[Русский](README.md) · **English**

A client music mod for **Minecraft Java 26.3 + Fabric**, intended for Windows.
Local tracks, Yandex Music and My Wave integration, a movable player, and optional 3D lyrics.
The interface uses Russian or English according to Minecraft's language setting.

- [Installation, controls, and settings](invumusicplayer/README.en.md)
- [Verification results and limitations](invumusicplayer/VALIDATION.en.md)
- [Dependencies and licenses](invumusicplayer/THIRD_PARTY.en.md)
- [Ready-to-install builds in GitHub Actions](https://github.com/Oskarrrrrsssss/Mods/actions/workflows/invumusicplayer.yml)
- [Project changes](https://github.com/Oskarrrrrsssss/Mods/pull/1)

Connect Yandex Music with a token inside the game. The integration uses an unofficial API;
playback with a real account has not yet been verified. Local music does not require an account.
The source code is in `invumusicplayer/`.
