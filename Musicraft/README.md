# Musicraft — Minecraft Java 26.3 / Fabric / Windows

Клиентский музыкальный мод. Полная сборка для Fabric 26.3 и 62 теста прошли на Windows,
включая реальное сохранение и чтение авторизации через Windows DPAPI. Для локальных
треков аккаунт не нужен. Интеграция Яндекс Музыки использует актуальные подписанные
запросы аудио и сессии «Моей волны»; с живым аккаунтом она ещё не проверена.
Реальный клиент Minecraft 26.3 также прошёл проверку интерфейса и рендера на Linux.
Результаты и границы проверки описаны в `VALIDATION.md`.

Сборки создаются в [GitHub Actions](https://github.com/Oskarrrrrsssss/Mods/actions/workflows/musicraft.yml).
Выбери успешный запуск и скачай артефакт `musicraft-fabric-26.3-windows-latest`.
После распаковки установи `musicraft-0.1.0-alpha.jar` в `mods` своей сборки Minecraft.

[Скриншоты реального запуска Minecraft](https://github.com/Oskarrrrrsssss/Mods/actions/runs/38181353522/artifacts/11717612730)
получены с синтетическим локальным треком для проверки.

## Возможности

- Компактный HUD слева сверху: обложка, название, исполнитель, время и прогресс.
- Полноценное окно плеера с библиотекой, поиском, паузой, перемоткой и переключением.
- Перетаскивание HUD мышью, выбор угла, масштаб, прозрачность и три цвета акцента.
- Режим без обложек. В нём остаются текст и управление.
- Локальные MP3, WAV и OGG/Vorbis из папки `music` внутри **папки текущей игры**.
- Необязательные синхронные 3D-строки перед игроком, настройка дистанции/высоты/размера,
  показ только при беге, сдвиг синхронизации. Отрисовка не создаёт сущности и не отправляет
  данные на сервер. Есть отдельное отключение в настройках и клавишей K.
- Экспериментальный прямой источник Яндекс Музыки: поиск, аудио, обложки, LRC,
  «Моя волна» и сообщения о начале/завершении/пропуске трека.
- Токен вводится внутри игры, маскируется и сохраняется через Windows DPAPI для текущего
  пользователя. Он не записывается в обычный JSON конфигурации и не передаётся на CDN.

## Клавиши по умолчанию

| Клавиша | Действие |
|---|---|
| M | Открыть плеер |
| F7 | Предыдущий трек |
| F8 | Играть / пауза |
| F9 | Следующий трек |
| K | Включить / выключить 3D-субтитры |

Переназначение: Настройки Minecraft → Управление → Назначение клавиш → Musicraft.
Экран плеера и экраны настроек не останавливают игру. Управление клавишами не требует
открывать экран плеера.

## Локальные треки

Для обычного лаунчера это `%APPDATA%\.minecraft\music\`. Если у сборки своя папка,
используется `music` внутри неё. Подпапки альбомов поддерживаются до четырёх уровней.
После добавления файлов нажми «Локальные» в плеере для обновления списка.

```text
music/
  Исполнитель - Название.mp3
  Исполнитель - Название.lrc       # необязательно, UTF-8
  Исполнитель - Название.png       # необязательно, .jpg тоже поддерживается
  Исполнитель - Название.json      # необязательно
```

JSON рядом с треком может содержать:

```json
{"title":"Название", "artist":"Исполнитель"}
```

Без JSON используются имя файла и разделитель ` - `. Встроенные ID3-обложки не извлекаются;
для своей обложки положи PNG/JPG рядом. Плеер работает и без обложек, и без текста.
Формат OGG в этой версии — Vorbis, не Opus. WAV должен быть совместим с JavaSound.

Пример собственного LRC (это демонстрационный текст, не слова существующей песни):

```lrc
[offset:0]
[00:02.00]Первая строка
[00:05.50]Следующая строка
[00:09.00]
```

Пустая строка с меткой времени скрывает субтитры на инструментальном участке.
Отключение 3D-текста не останавливает музыку и не скрывает панель плеера.

## Яндекс Музыка

Плеер → Аккаунт → вставить OAuth-токен собственного аккаунта → Подключить.
Пароль аккаунта мод не запрашивает. Кнопка «Как получить токен» открывает
[инструкцию библиотеки yandex-music](https://yandex-music.readthedocs.io/en/main/token.html).
Автоматический вход через браузер и OAuth собственного зарегистрированного приложения
не реализованы. Можно вставить токен или официальный адрес страницы с `access_token`. Токен не нужно отправлять автору мода или в чат.

Используется **неофициальный API**. Подписка, регион и доступность трека определяются
Яндексом. Если сервис отдаёт только превью, оно не выдаётся за полный трек.
Синхронного текста может не быть; в таком случае музыка продолжает играть без субтитров.
Неподдерживаемые ответы показывают ошибку в плеере. Аудио загружается в память перед
воспроизведением (до 64 МиБ на трек) и не записывается в локальную библиотеку.
Переключение отменяет предыдущую загрузку; устаревший запрос не меняет новый трек.
«Моя волна» использует отдельную сессию рекомендаций и учитывает время прослушивания,
паузы и пропуски. Перемотка не выдаётся за прослушанное время.

Файл авторизации: `config/musicraft-auth.dat`. Он зашифрован средствами Windows и
привязан к текущему пользователю. Настройки: `config/musicraft.json`.

## Сборка на Windows

Нужен **JDK 25**, доступный через `JAVA_HOME` или `PATH`, и интернет для зависимостей.
Сборка основана на официальном примере Fabric 26.3, без Yarn/mappings для необфусцированной игры.

```bat
build-windows.cmd
```

Или в терминале:

```bat
gradlew.bat build
```

После **успешной** сборки положи `build/libs/musicraft-0.1.0-alpha.jar` в `mods` своей
сборки Minecraft 26.3. Нужны Fabric Loader 0.19.5+ и Fabric API 0.162.0+26.3.
Файл с суффиксом `-sources.jar` устанавливать не нужно. Не устанавливай отдельный `-gametest.jar`: он нужен только для автоматической проверки.

## Проверка

`gradlew.bat test` запускает тесты ядра. Полная CI-сборка на Windows проверила все 62
теста, в том числе нативный DPAPI; на Linux прошли 61 и пропущен один Windows-тест.
Клиентские тесты запускают настоящий Minecraft через отдельный тестовый мод:

```bat
gradlew.bat runProductionClientGameTest
```

На Linux для этого нужен Xvfb. Для проверки кодеков и интерфейса используются только
синтетические локальные файлы, аккаунт и реальная музыка не загружаются.
Результаты и границы проверки описаны в `VALIDATION.md`.
